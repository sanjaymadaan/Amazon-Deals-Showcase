# 🏷️ Amazon Deals Showcase

A simple, responsive web application for showcasing and discovering selected Amazon products and deals through an easy-to-use interface.

🌐 **Live Website:**
https://amazon-deals-showcase.vercel.app/

---

## 📌 About the Project

**Amazon Deals Showcase** is a web-based product showcase designed to provide users with a convenient way to browse, search, and explore Amazon products from a centralized interface.

The application presents products in an organized manner and provides direct access to Amazon product/deal pages. It is designed with a clean, responsive interface that can be accessed from desktop and mobile devices.

The project also demonstrates how a lightweight frontend application can be deployed as a live website using **Vercel** and maintained through **GitHub**.

---

## ✨ Key Features

* 🏷️ **Amazon Product Showcase**

  * Display selected Amazon products and deals in a user-friendly interface.

* 🔍 **Product Search**

  * Search for products using the integrated search functionality.

* 📂 **Product Categories**

  * Browse products based on available categories and selections.

* 🔄 **Refresh Products**

  * Refresh the displayed product information.

* 📱 **Responsive Design**

  * Designed to work across desktop, tablet, and mobile devices.

* 🔗 **Amazon Product Links**

  * Users can access the corresponding Amazon product/deal page.

* 📷 **Barcode / QR-Based Access**

  * The website provides a facility to scan a barcode/QR-style link using a smartphone camera to open an Amazon link.

* 💬 **Contact Section**

  * Provides a mechanism for visitors to contact the website owner.

* 👁️ **Page Visit Counter**

  * Displays total page visits.

* ⚡ **Lightweight Frontend**

  * Built using standard HTML, CSS, and JavaScript without requiring a heavy frontend framework.

```text

        │
        ▼
   Build / Deployment
        │
        ▼
Live Website
        │
        ▼

```

Any future changes pushed to the connected GitHub repository can be used to update the deployed application through the Vercel deployment workflow.
